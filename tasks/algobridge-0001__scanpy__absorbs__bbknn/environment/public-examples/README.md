# Public examples

`task_cases.py` contains five visible deterministic inputs. `expected.json` is generated by the
locked Scanpy + BBKNN reference and records neighbor identities, distances, and both CSR graphs.

After editing `/testbed`, run `/opt/task-tools/run-public-examples`. Public examples aid local
development; the verifier uses a separate set of 15 hidden inputs and additional hard gates.
