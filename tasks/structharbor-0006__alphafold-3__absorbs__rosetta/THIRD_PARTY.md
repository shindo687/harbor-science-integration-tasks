# Third-party provenance and license boundary

## AlphaFold 3 host

The environment contains the source-code snapshot of
`google-deepmind/alphafold3` at commit
`29596b97021cfc941b1993249969c4f268efdbab`, licensed under Apache-2.0.
Model weights are not included.  Exact hashes are in `source-lock.json`.

## Rosetta donor/reference

Rosetta is source-available under the Rosetta Software Non-Commercial License,
not an OSI open-source license.  Its source lock is
`fa5ce209894d40d0cb2bb6676757b7b1ce4abc87`.

No Rosetta source, executable, shared library, database, score-function
parameter file, or derived implementation is shipped in this task.  The only
Rosetta-derived artifact is a JSON table of scalar `InterfaceAnalyzer/ref2015`
outputs generated by an authorized local installation.  Those scalars are used
solely for rank correlation, not as an executable reference and not as a claim
of Ref2015 numerical compatibility.  The local executable hash and generation
settings are recorded in the JSON and in `source-lock.json`.

Users who need Rosetta itself must obtain it from the official RosettaCommons
repository and comply with its license independently.
