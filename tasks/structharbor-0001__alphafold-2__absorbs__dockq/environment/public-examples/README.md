# Public DockQ examples

`examples.json` contains five input/output pairs generated by the locked original
DockQ commit named in the task. They cover identity, interface displacement,
rigid-body invariance plus interface error, automatic chain mapping, and an
explicit mapping.

From the Agent container, check an implementation with:

```bash
python3 /examples/verify_examples.py \
  /testbed/alphafold/common/dockq_score.py
```

The checker uses the same absolute/relative tolerance (`5e-4`) as the hidden
verifier and requires the exact result schema.
