## Task

Work in the BWA 0.7.17 source tree at `/testbed`. Add a native bounded
biallelic SNV-calling command that consumes SAM emitted by BWA-MEM.

Read-only FreeBayes 1.3.6 source and documentation are available at
`/opt/freebayes-source` for study. Your submitted `/testbed` must remain a
standalone BWA implementation: it must not execute, import, dynamically link,
download, vendor, or otherwise require FreeBayes, vcflib or donor code at
build time or runtime.

## Required interface

The submitted tree must continue to build with `make`. Add this command:

The starting Makefile has one documented environment compatibility change:
`-fcommon` is appended to CFLAGS so pristine BWA 0.7.17 links with GCC 10+.
Preserve equivalent buildability in the submitted tree.

```bash
./bwa snv-call \
  -f REFERENCE.fa \
  -s SAMPLE \
  -p 1|2 \
  --min-base-quality INT \
  --min-mapping-quality INT \
  --min-alternate-count INT \
  --min-alternate-fraction FLOAT \
  --theta FLOAT \
  INPUT.sam > OUTPUT.vcf
```

`INPUT.sam` is an uncompressed SAM stream produced by the same submitted
`bwa mem` from the supplied reference and FASTQ reads. The bounded subset is:

- single-end reads of 20--250 bases;
- haploid or diploid samples;
- biallelic SNVs only;
- no indels, MNPs, symbolic alleles or structural variants;
- primary mapped alignments only; secondary, supplementary, duplicate,
  QC-fail and unmapped records are ignored;
- Phred+33 base qualities and ordinary BWA CIGAR operations;
- finite `theta` and alternate-fraction values in their documented ranges.

Emit normalized VCF 4.2 with one sample and biallelic SNV rows. Candidate rows
must expose `DP` in INFO and `GT:DP:AD:GL:GQ` in FORMAT. Preserve reference
contig order and coordinate order. Keep all existing BWA commands and output
unchanged when `snv-call` is not selected.

## Public examples

Five deterministic examples are available at `/public-cases`. Each directory
contains `reference.fa`, `reads.fastq`, `parameters.json`, the intended locus
metadata and `expected.json` generated by the locked real reference pipeline.
They cover diploid and haploid calling, two-locus ordering, and a filtered
no-call. They are examples only; the reward is computed from separate private
fixtures.

## Differential grading contract

For each private fixture, the verifier will:

1. run locked pristine BWA-MEM 0.7.17 on the reference and reads;
2. convert/sort/index its SAM with locked samtools 1.13;
3. run real locked FreeBayes 1.3.6 with the matching ploidy, quality, count,
   fraction and theta settings, `--use-best-n-alleles 2`,
   `--haplotype-length 0`, SNP-only observations,
   `--report-genotype-likelihood-max`, and `--genotype-qualities`;
4. normalize the reference VCF to the required fields;
5. run submitted BWA-MEM and submitted `bwa snv-call` on the same data;
6. compare sites, alleles, GT, DP and AD exactly, and each GL/QUAL/GQ value
   with absolute tolerance `1e-4`.

Compilation, source provenance, legacy BWA-MEM parity and donor-isolation
checks will be hard gates. The candidate phase will run without donor binary,
package, source, dynamic library or network access and as an unprivileged
user.

There are 15 private cases. Each case passes only when every required field
passes; the reward is `passed / 15`. The cases cover homozygous-alternate and
heterozygous evidence, haploid reference/alternate genotypes, multiple loci,
base- and mapping-quality boundaries, alternate count/fraction thresholds,
balanced forward/reverse reads, read-position variation, and SAM duplicate
filtering. A deterministic subset of SAM records may have ordinary exclusion
flags added after BWA-MEM; both the real reference and submitted caller receive
the same annotated alignment records.

The verifier first evaluates all references while the donor exists, then
removes the FreeBayes executable, donor/pristine sources, system BWA and
samtools before compiling and running the candidate as unprivileged UID
`10001`. Static donor-copy/process-execution checks and unchanged legacy
BWA-MEM output are zero-reward hard gates.
