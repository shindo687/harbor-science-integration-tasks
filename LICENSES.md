# License scope

This repository is an aggregation of independently maintained Harbor tasks and
locked snapshots of third-party source trees. It does not impose one umbrella
license on all nested content.

- Each directory under `tasks/` retains the license and provenance files from
  its corresponding standalone repository.
- Embedded upstream and donor source snapshots remain subject to their own
  licenses.
- `task-sources.json` identifies the standalone repository and exact commit for
  every imported task.

Review the license files and source-lock metadata inside a task before
redistributing or modifying that task.
